# КОНСУМАЦИЯ — браузерная хоррор-игра

Восстановлена 13 октября 2026 из облачной копии сессии «Браузерная horror-игра в магазине»
(5 сентября 2026). Локальная запись этой сессии на Маке удалена автоочисткой Claude Code,
сама игра лежала в `~/Downloads/magicui-main/index.html`.

Файл собран так же, как его собрала исходная сессия: целиком написанный `index.html`
плюс две правки, которые она внесла после проверки в браузере (защита от нулевого
размера окна при запуске).

## Запуск

Открыть `index.html` двойным кликом. Нажать «Войти в зал».

Управление: WASD — ходьба, Shift — бег, мышь — поворот. На телефоне — виртуальный джойстик.
Цель — найти 3 ключа и выйти через служебный выход.

## Лицо и тело монстра

Игра ищет рядом с собой `face.jpg` (лицо) и `body.jpg` (манекен). Их можно положить в эту
папку или перетащить на стартовый экран. Без них игра рисует процедурное лицо и манекен.

Фотографии в репозиторий не добавлены: репозиторий публичный, а на `face.jpg` лицо
реального человека.
